🧠 The 6 Foundational Pillars of C++ Exam Success

Master these core principles that CDAC questions repeatedly test across all 65 questions:

1. LIFO Stack Destruction Order

Stack objects are destroyed in the exact reverse order of their construction. At block exit or return, the most recently constructed object is cleaned up first.

2. Non-Virtual Static Dispatch

Without the virtual keyword on a base member function, C++ binds the call at compile time based strictly on the pointer type, not the runtime object!

3. The Virtual Destructor Mandate

Deleting a derived object via a base pointer (delete pBase;) without a virtual ~Base() skips the derived destructor, leaking resources!

4. Rule of Three & Double-Free

If a class manages dynamic memory (raw pointer), a default compiler copy constructor causes a shallow copy, leading to an immediate double-free crash when both objects delete the same address.

5. Virtual Base Classes & Diamond Problem

When two derived classes inherit from a common base, inheriting via virtual public Base prevents duplicate subobjects and ambiguity in the leaf class.

6. Size of Empty Class & Indirection

An empty class in C++ has sizeof = 1 byte to ensure distinct object addresses. Accessing objects via pointers is called indirection.
