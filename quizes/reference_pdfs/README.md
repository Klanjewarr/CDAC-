Welcome to your dedicated folder for all study references, question banks, lecture notes, and syllabus PDFs for CDAC CCEE/CMCE exam preparation!

## Directory Layout:
- `reference_pdfs/Java_OOP/` : Drop all Object-Oriented Programming with Java PDFs, Sunbeam notes, syllabus guides, and previous question papers here.
  - *Already included*: `CORE JAVA CDAC EXAM PAPAR Real_1.pdf` (The authentic 40-question PGDAC CCEE exam paper).
- `reference_pdfs/ADS/` : Drop all Algorithms and Data Structures notes, complexity cheat sheets, and problem sets here.

Whenever you download a new PDF from Telegram, Sunbeam drive, or the internet, simply drag and drop it into the respective folder above!
